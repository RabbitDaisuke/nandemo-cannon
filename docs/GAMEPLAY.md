# ゲーム本体と進行
Godot 4.7.2のゲーム本体を`src/game.gd`で実装した。各マップの背景、独立した静的地形、剛体アイテム、大砲、液体、火・氷の管理層、上部UIを組み合わせる。第1〜16面をプレイでき、第17〜20面はルール未決定のマッププレビューとして選択できる。未指定の面へ勝手に投射リストや攻略ルールを追加しない。
## 操作と15投
大砲をドラッグして角度と火力を調整し、クリック／タップで発射する。右上のスライダーでも調整できる。キーボードは上下で角度、左右で火力、Spaceで発射、Rで再挑戦、MまたはEscapeでマップ選択。ゲーム内の説明とメニューには同梱のSVGから作ったビットマップフォントを使う。
1ステージは15投。指定済みの投射順を保持し、爆弾・消火用アイテムなどの前提順序をシャッフルしない。各投射では現在の砲口と向きから物体を生成し、物体の後端が砲口の外へ出るよう配置する。火力と質量で初速を決め、発射時の小さな回転速度だけをSEEDから生成する。
初期照準は通常35度・65%、月面は25度・22%、路地裏と火山は35度・34%。軽い火炎瓶や新聞が最初から目標を大きく飛び越えない値に調整した。路地裏では初期照準の火炎瓶でごみが燃え、火山では初期照準の新聞が床から着火して消滅することを実物理で確認した。
第15面の砂場では全117種類から次の物体を選べる。選択は5ページの一覧で行い、最後のページまでアクセスできる。好きな物体を選んでも残り投数は増えない。現在選択した物体は次の投射にも引き継ぐため、同じ物体を続けて試せる。
## 得点と終了
水色の点線枠へ物体の全当たり判定が入った場合に得点へ加算する。部分的に重なるだけでは加点しない。物理接触の微小な食い込みに対して1.5pxの許容値を設ける。破壊された本体と演出の破片は得点から除外する。第7面では初期配置の花と時計が得点対象で、大砲を邪魔する大きな洗濯機は対象外とする。
15投後、全物体が1.5秒静止したら結果を確定する。水流や氷床で物体が動き続ける場合も、最後の投射から12秒でその時点の得点を確定し、結果画面へ移る。動いているまま確定した場合は結果に明記する。結果表示中は物理とゲーム内時計を停止する。ステージごとの最高得点をGodotの`user://progress.json`へ保存する。
## 再挑戦と一時停止
SEEDは16桁の16進数。再挑戦では同じSEEDを維持し、発射時の乱数や爆発抽選を繰り返せる。異なる端末で剛体物理の全座標までビット単位で一致することは保証しない。SEEDメニューで値を編集すると同じステージを最初からやり直す。
マップ、アイテム一覧、SEED、結果の表示中はゲーム内時計と剛体を停止する。Webでは`document.visibilitychange`をJavaScriptBridgeで受け、タブが非表示になった際に一時停止画面を開く。復帰後はRESUMEで再開し、非表示中の時間を燃料や燃焼時間へまとめて加算しない。JavaScriptのコールバック参照を保持し、ゲームノード終了時には登録を解除する。ローカルブラウザによる実動作確認は行っていない。
## 実行して確認した範囲
`tests/game_checks.gd`は実際のゲームシーンをheadlessで起動し、20マップの読み込み、初期の冷蔵庫投射、同じSEEDの発射乱数、マップ選択のクリック先、既存得点アイテム、奈落での落下消滅、117種類のアイテム選択、火のチュートリアルの初期投射、15投の進行、動き続ける物体があっても12秒で結果が出ることを確認する。Godot 4.7.2で103項目が成功した。プレビュー用の物体位置はこの実物理から取得し、Node.jsでSVG原本と自作字形を再配置して画像化する。
`previews/game-01-initial.png`は開始状態、`game-01-after-five.png`は実際に5投した後、`game-04-alley.png`は火炎瓶でごみに着火した場面、`game-16-ice.png`は氷床へ靴を投射した場面。これらはGodotの内部状態をNode.jsで再描画した確認画像であり、実ブラウザやGPUの画面キャプチャではない。ブラウザ互換性とGPU描画性能の実測とは区別する。
