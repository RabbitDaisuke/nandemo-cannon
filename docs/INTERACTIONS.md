# 火・水・氷・爆発の実装

`src/hazard_system.gd`が火、燃料、凍結、爆発を管理し、`src/liquid_field.gd`が有限の水滴、水セル、水流領域を管理する。物体本体は`ThrowBody`の剛体を使い、表示はSVGアセットを読み込む。接触、遮蔽、水滴の反射にはGodotの実際の形状照会を使う。

画面の物体名と各面の案内は`data/ui-ja.json`の日本語を表示する。効果の管理は物体IDとbehaviorを使い、表示名に依存させない。

## 火と燃料

火炎放射器は発射時から6秒で燃料が尽き、空の容器のSVGへ切り替わる。炎と噴流は6枚のSVGを毎秒12フレームで更新する。噴射方向は剛体の回転に追従し、5本の照会線で最初に当たった形状まで届く。壁、金属容器、フライパンなどの固体が炎を遮る。

燃える指定のある木箱、丸太、ゴミなどは一定時間燃えた後に消滅する。濡れ、凍結は着火を遅らせる。普通の床の炎は水で消え、熱源指定のコンロは継続する。焚火と燃料ランタンは燃料時間を1本だけ持つ。火炎放射器は水滴・水セル・川の水に触れると噴射を即停止し、残燃料を終了して停止後のSVGへ替える。水から出しても勝手に噴射を再開しない。

## 水と傘

水風船などは衝突時に指定量を一度だけ放出する。水入りの容器は継続荷重、爆発、容器の焼失でも中身を放出する。荷重の初期値は力7840の超過が0.4秒続く条件で、床の支持反力は除外する。放出済みのフラグを各経路で共有するため、同じ破損が重なって通知されても水を増やさない。水源タイルは毎秒の供給量と総供給量を持ち、上限まで放出すると止まる。水流領域は指定方向への力、水中抵抗、浮力を剛体へ与える。流されないテーブルは`flowResponse: 0`で水流からの押す力を受けないが、水中抵抗や濡れの対象にはなる。

水滴は移動前後を線分で照会する。傘は天蓋・軸・持ち手の全当たり判定で水を反射する。水セル間の移動と水滴からセルへの変換にも線分照会を使い、細い軸をすり抜けないようにする。スポンジなどの吸水物は水滴・接触水セル・川から容量まで吸水し、吸った比率で質量が増す。飽和後は吸わない。川ではスポンジを2個投射する。洗面台は盆内の貯水量が40単位に達したら蛇口を停止し、吸水で減っても再開しない。既存の総供給量上限も維持する。水流の矢印テクスチャは波模様に置き換え、押力は維持する。

有限水は16pxのセルを最大256個、水滴を最大96個まで扱う。1セルの内部容量は4単位で、満杯になった水を単純な丸めで消さない。水滴をセルに移せない場合は残量を水滴に保持して再試行する。放出時に両方の上限へ達した場合の受け入れ拒否、画面外への排水、吸水物へ移った量を別々に記録する。`current_volume()`は現在の水滴と水セルの合計を返す。固定された川の水流領域は無限の背景水として別扱いで、川から作った氷の分は`region_drawn_volume`に記録する。これはゲーム用のセル近似であり、連続流体の圧力計算ではない。

## 氷と爆発

冷気は周囲を消火し、有限水と川の表面を8秒間凍らせる。凍ったセルには摩擦0.025の`StaticBody2D`を作り、融解時には当たり判定を外して水へ戻す。凍結・融解で元の水量を上書きしない。氷塊は熱を蓄積すると指定量の水へ変わり、濡れ状態でも融解できる。

カップアイスとかき氷も`ice_mass`として熱で水へ変わり、水ヨーヨーは破損時に水を放出する。永久氷床は`iceFloor`と表面領域の設定で判定し、ステージ番号に依存させない。従来の氷床は暫定的に第18面へ移している。

爆発は爆心からの距離、爆発強度、0〜1の爆発耐性で破壊確率を計算し、爆弾と対象の組ごとに一度だけ乱数を引く。耐性1は確率0になり、耐性0は距離と強度によって確率が決まる。爆風の遮蔽は地形に限定し、積み上げた手前の木箱が奥の木箱を完全に守る状態を防ぐ。炎の遮蔽は引き続き物体も含める。船のチュートリアル木箱は、届いた爆発を3回受けて壊れる明示的な例外であり、同じ爆弾の再通知は数えない。

第19面の花火玉・ロケット花火・噴出花火は、発射時からそれぞれ2.4秒・1.8秒・3秒で炸裂する。着弾後も剛体として残り、導火線が切れると既存の爆発・インパルス・着火を一度だけ発生させる。紅白の台には木箱と燃えるゴミを置く。第10面の2投目は専用ID`blast-bomb`で、通常の爆弾を変更せず半径220・強度1.5・押力倍率2.2へ強化する。

## 実行した検証

Godot 4.7.2のheadless実行で`tests/hazard_checks.gd`を検証した。最新の件数・結果は`previews/hazard-checks.json`を参照する。実際の剛体、照会、SVGリソースを使い、6秒の燃料寿命と表示変更、丸太の燃焼、焚火、ランタン消火、水の一度きりの放出、床の消火、傘の天蓋・軸・持ち手の反射、水流と水中抵抗、金属容器の炎遮蔽を確認した。荷重試験では床に置いた水ボトルが内容物を保ち、質量12の木箱を載せると荷重破損が一度だけ起きて8単位を放出した。水タンクが爆発で壊れた場合の24単位、ボトルが燃え尽きた場合の8単位も確認した。

9.75単位の水を複数セルへ入れて45回流した後も、現在量と排水量の合計は9.75単位を維持した。256個の満杯セルへ512単位を追加する上限試験では、水滴96個の上限を守り、現在量と明示的な受け入れ拒否量の合計は1536単位だった。さらに3.2単位の凍結・融解で量が変わらないこと、濡れた氷塊が5単位の水へ変わること、爆発耐性の両端、6個の木箱が3回目の爆発で壊れることを確認した。花火は実際の床への衝突後も残り、設定時間後だけ炸裂して生存物体を吹き飛ばし、木材へ着火することを確認した。ブラウザを起動せずに行ったGodotネイティブの検証であり、Safari・Chrome・Firefox実機での描画や操作の検証は別途必要になる。
