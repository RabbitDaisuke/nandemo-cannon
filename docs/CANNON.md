# 可動砲身の大砲
台座を固定し、砲身だけを独立した回転軸で動かす。従来の一枚絵を回転させる構成を置き換えた。黒い輪郭、木製の車輪と架台、金色の砲身、補強帯、砲尾、側面軸受をSVGで直接記述した。通常素材は必要な範囲のviewBoxを持ち、拡大用の広い透明キャンバスを付けない。黄色の選択輪郭は別のシルエットとして重ねる。
## 座標と部品
|部品|SVG寸法|Node2Dからの位置|役割|
|---|---|---|---|
|base.svg|150×78|−51, −78|地面に固定する架台と車輪|
|barrel.svg|144×50|回転軸から−104, −25|砲身、補強帯、砲尾|
|trunnion.svg|26×26|−13, −68|回転軸の手前に重ねる軸受|
|base-highlight.svg|158×86|−55, −82|台座の黄色輪郭|
|barrel-highlight.svg|152×58|回転軸から−108, −29|砲身と一緒に回る黄色輪郭|
大砲ノードの原点は地面上の設置位置。回転軸は原点から`(0,−55)`。砲身SVG上の回転中心は`(104,25)`、砲口中心は`(0,25)`。0度では左へ向く。正の仰角では左上を向き、発射方向は`(−cosθ,−sinθ)`となる。角度範囲は5〜85度。初期値は35度、火力65%。
砲身の回転行列から砲口のワールド座標と発射方向を求める。弾を固定座標から飛ばしたり、絵だけを回して発射方向を据え置いたりしない。発射時はそのフレームの砲口から発射信号を出した後、砲身だけを最大10px後退させる。反動中も台座と回転軸は動かない。
## 操作
大砲の台座または砲身からドラッグを始める。上へドラッグすると仰角が増え、左へドラッグすると火力が増える。移動量7px以下のクリック／タップで発射する。調整ドラッグの終了では発射しない。上部UIから始まった操作は取り込まない。大砲から始めたドラッグはUIの上で離しても終了し、操作が捕捉されたままにならない。タッチ直後の合成マウスイベントは抑止して二重発射を防ぐ。
マウスが大砲上にあるときとドラッグ中は、台座と砲身の輪郭を黄色にする。選択輪郭も砲身の角度へ追従する。残弾切れや画面切り替え時の発射可否はゲーム側が`set_enabled()`で制御する。モジュール内にも0.45秒の発射間隔を設け、クリック連打による同一フレームの多重発射を防ぐ。
## 実装API
`AimCannon.configure(ground_position)`で設置する。`set_aim(elevation_degrees,power)`で角度と火力を変更する。火力の範囲は0.15〜1.0。`fire()`で発射を要求する。`get_muzzle()`、`get_launch_direction()`、`pivot_global()`が現在のワールド座標系を返す。
`fired(direction,power,origin)`をゲーム本体が受けて物体を生成し、質量に応じたインパルスを与える。大砲側は次に出る物体の質量や弾数を決めない。`aim_changed(elevation,power)`で上部UIを更新できる。UIのスライダーからは`set_aim()`を呼ぶ。
## 画像確認
`node tools/render-cannon.mjs`は手書きSVGを配置し、15度・35度・75度のプレビューをsharpでレンダリングする。大砲の形をNode.jsの描画命令で作らない。`previews/cannon-angles.png`が比較画像、`cannon-15.svg`・`cannon-35.svg`・`cannon-75.svg`が外周を詰めた拡大用の合成SVG。これらは視覚確認用で、ゲームでは部品ごとのSVGを読み込む。
