# 可動砲身の大砲
台座を固定し、砲身だけを独立した回転軸で動かす。黒鉄の短く太い砲身と車輪付き架台を画像生成で2案作り、B案を採用した。原稿は`assets/generated/cannon-sheet.webp`、生成指示は同ディレクトリの`prompts.json`。`tools/prepare-generated-art.mjs`がパーツを切り出し、透明余白を詰めてlossless WebPへ変換する。旧金色SVGは比較用の原稿として残し、ゲームはWebPを使用する。
## 座標と部品
|部品|論理寸法|Node2Dからの位置|役割|
|---|---|---|---|
|base.webp|150×78|−51, −78|地面に固定する架台と車輪|
|barrel.webp|144×50|回転軸から−104, −25|砲身、補強帯、砲尾|
|trunnion.webp|26×26|−13, −68|回転軸の手前に重ねる軸受|
大砲ノードの原点は地面上の設置位置。回転軸は原点から`(0,−55)`。砲身上の回転中心は`(104,25)`、砲口中心は`(0,25)`。0度では左へ向く。正の仰角では左上を向き、発射方向は`(−cosθ,−sinθ)`となる。角度範囲は5〜85度。初期値は35度、火力65%。
砲身の回転行列から砲口のワールド座標と発射方向を求める。弾を固定座標から飛ばしたり、絵だけを回して発射方向を据え置いたりしない。発射時はそのフレームの砲口から発射信号を出した後、砲身だけを最大10px後退させる。反動中も台座と回転軸は動かない。
## 操作
大砲の台座または砲身からドラッグを始める。上下ドラッグで仰角、左右ドラッグで火力を変更する。第1面では十字矢印と日本語の案内を表示する。画面下端のスライダーでも調整でき、方向キーは上下で角度、左右で火力を変える。大砲の移動量7px以下のクリック／タップで発射し、UI以外のゲーム面は左クリック・中クリックでも発射できる。調整ドラッグの終了では発射しない。UIから始まった操作は取り込まない。大砲から始めたドラッグはUIの上で離しても終了し、操作が捕捉されたままにならない。タッチ直後の合成マウスイベントは抑止して二重発射を防ぐ。
マウスが大砲上にあるときとドラッグ中は、架台・砲身・軸受を合成した外周だけを黄色にする。部品同士の継ぎ目を輪郭として強調せず、砲身の角度へ追従する。装填物は投射後と同じ実寸で大砲へ重ね、次の物体のプレビューとは区別する。残弾切れや画面切り替え時の発射可否はゲーム側が`set_enabled()`で制御する。モジュール内にも0.45秒の発射間隔を設け、クリック連打による同一フレームの多重発射を防ぐ。
## 実装API
`AimCannon.configure(ground_position)`で設置する。`set_aim(elevation_degrees,power)`で角度と火力を変更する。火力の範囲は0.15〜1.0。`fire()`で発射を要求する。`get_muzzle()`、`get_launch_direction()`、`pivot_global()`が現在のワールド座標系を返す。
`fired(direction,power,origin)`をゲーム本体が受けて物体を生成し、質量に応じたインパルスを与える。大砲側は次に出る物体の質量や弾数を決めない。`aim_changed(elevation,power)`で照準UIを更新できる。UIのスライダーからは`set_aim()`を呼ぶ。
## 画像確認
`./build.sh preview`が`tools/render-cannon.mjs`を呼び、実際に使うWebPパーツを配置してsharpで確認画像を作る。`previews/cannon-candidates.png`が2案比較、`previews/cannon-angles.png`が15度・35度・75度の首振り比較。Nodeは大砲自体を描かず、生成した絵の配置・回転・形式変換を担当する。
