# 剛体と接触処理

`src/throw_body.gd`は小物1個を`RigidBody2D`として生成する。SVGの元座標から`pivotSource`を引き、`worldScale`を乗じて、絵と全当たり判定に同じ変換を適用する。透明部分を広げて見かけの大きさを調整しない。四角形、円、複数の多角形を扱い、凹多角形はGodotの凸分解で分割する。分割した形状にも元のfixture番号を保持するため、車輪や靴底の指定がずれない。

213種類の小物に同じ処理を使う。強力爆弾は通常爆弾と絵・fixtureを共有する別IDで、通常爆弾の性能は変更しない。ドーナツは8個の凸fixtureで輪を作り、中央の描画・当たり判定を空ける。白米は器のない独立した食物の塊。レストランの皿と火山の火口は静的地形の凹多角形を凸分解し、内部の空間を保つ。第1面だけは画面左右端の外側に静的な衝突壁を置く。

画面上のかな・カタカナ名は`data/ui-ja.json`から読み、物理処理は従来の物体IDを使う。日本語表示への変更でfixtureや物理属性は変えない。

スケートボード、手押し車、台車は、指定車輪の接触と物体の上向きに対する床法線を確認し、条件を満たす間だけ低摩擦になる。裏返り、横倒し、空中では通常摩擦へ戻る。速度を固定する補正、床への吸着、空中の姿勢固定は行わない。斜面や衝突による加速度はGodotの剛体運動を使う。

氷床では接触位置の摩擦値をワールドから取得する。最新指定のグリップ靴は冷蔵庫と同じ通常摩擦0.55・反発0.08の剛体とし、靴底だけの追加制動を使わない。氷上では姿勢にかかわらず通常の低摩擦を受ける。

グリップ靴も重力、回転、慣性、衝突を受ける通常の剛体であり、接地中も固定しない。ゴムは通常時の反発を持ち、凍結中だけ反発を0にして衝撃・荷重・爆風で壊れやすくする。凍結が切れた存命物体は元の反発へ戻る。

第29面の吊り下げライトと第31面の移動足場は`src/moving_terrain.gd`の`AnimatableBody2D`を使う。SVGと衝突形状を同じ変換で動かし、手動メニューを開いても位相と衝突を進める。

永久氷床は`iceFloor`フラグで設定する。元の第16面の氷床は暫定的に第18面へ移したが、摩擦処理自体はステージ番号へ依存しない。

衝突破損は接触の法線速度と有効質量によるエネルギーを使う。ソルバーで既に減速した衝突を見落とさないよう、新しい接触では前の物理ステップの速度も比較する。生成後0.15秒の配置整理中は破損を判定しない。積み重ねの破損は上側から受ける圧縮インパルスを力へ変換し、短い平滑化の後、閾値超過が設定時間続いたら発火する。地面の支持反力は上荷重へ二重加算しない。

破損の要求は一度だけ遅延確定し、ハザード側が中身の放出を処理してからワールドが本体と得点を除去する。水入り容器にも継続荷重の判定を適用し、衝突以外の破損でも水を放出する。火・濡れ・凍結・燃料の時間はワールドの担当であり、このノードでは重複減算しない。傘の水判定用の点内外判定は天蓋だけでなく全fixtureを対象とする。

## 接触の検証

`tests/body_checks.gd`はGodot 4.7.2のheadless実行で、車輪側と裏返りの移動量、氷上の靴底側と裏返りの移動量を比較する。靴の両姿勢で余計な制動を加えずに滑ることと、冷蔵庫と同じ摩擦・反発値を使うことを確認する。傘の軸と持ち手の点内外判定、強い法線衝突での破損、床の支持反力だけでは壊れないこと、上からの継続荷重で壊れることも検証対象にする。

追加物体と地形ではドーナツの穴と輪、凹皿の内部・底・斜面、食品の着地、移設後の氷床、第1面の左右壁、火山の頂部と火口を照会する。投射枠は15個・SEED再現・ボーリング先頭2投・川のスポンジ2個を検証する。最新の件数・結果・移動距離は`previews/body-checks.json`を参照する。水入り容器の破損放出、花火、有限吸水、水源停止、水による火炎放射器停止は`tests/hazard_checks.gd`で別途検証する。これらはGodotネイティブの試験であり、ブラウザ実機の成功を意味しない。
