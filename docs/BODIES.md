# 剛体と接触処理
`src/throw_body.gd`は小物1個を`RigidBody2D`として生成する。SVGの元座標から`pivotSource`を引き、`worldScale`を乗じて、絵と全当たり判定に同じ変換を適用する。透明部分を広げて見かけの大きさを調整しない。四角形、円、複数の多角形を扱い、凹多角形はGodotの凸分解で分割する。分割した形状にも元のfixture番号を保持するため、車輪や靴底の指定がずれない。
スケートボード、手押し車、台車は、指定車輪の接触と物体の上向きに対する床法線を確認し、条件を満たす間だけ低摩擦になる。裏返り、横倒し、空中では通常摩擦へ戻る。速度を固定する補正、床への吸着、空中の姿勢固定は行わない。斜面や衝突による加速度はGodotの剛体運動を使う。
氷床では接触位置の摩擦値をワールドから取得する。滑り止めの靴は、指定靴底の接触にのみ追加摩擦インパルスを加える。接線速度を止めるための必要量と、法線インパルスに比例する摩擦限界の小さい方に制限し、接触相手が剛体なら反対向きのインパルスも渡す。靴全体を世界へ固定する処理や、裏返りでも効く高摩擦設定は使わない。
衝突破損は接触の法線速度と有効質量によるエネルギーを使う。ソルバーで既に減速した衝突を見落とさないよう、新しい接触では前の物理ステップの速度も比較する。生成後0.15秒の配置整理中は破損を判定しない。積み重ねの破損は上側から受ける圧縮インパルスを力へ変換し、短い平滑化の後、閾値超過が設定時間続いたら発火する。地面の支持反力は上荷重へ二重加算しない。
破損の要求は一度だけ遅延確定し、ハザード側が中身の放出を処理してからワールドが本体と得点を除去する。水入り容器にも継続荷重の判定を適用し、衝突以外の破損でも水を放出する。火・濡れ・凍結・燃料の時間はワールドの担当であり、このノードでは重複減算しない。傘の水判定用の点内外判定は天蓋だけでなく全fixtureを対象とする。
## 接触の検証
Godot 4.7.2のheadless実行で、`tests/body_checks.gd`の12項目が通過した。水平速度220を与えて90物理ステップ後のスケートボードの移動量は、車輪側で147.55px、裏返りで38.46pxだった。氷床で水平速度180を与えた靴は、靴底側で76.61px、裏返りで119.06px移動した。靴は転倒や滑り自体を禁止せず、靴底の接触中だけ摩擦を追加している。傘の軸と持ち手の点内外判定、強い法線衝突での破損、床の支持反力だけでは壊れないこと、上からの継続荷重で壊れることも確認した。これはGodotネイティブの物理試験であり、ブラウザ実機の成功を意味しない。
試験結果と移動距離は`previews/body-checks.json`へ保存する。水入り容器の荷重、爆発、燃焼による放出は`tests/hazard_checks.gd`で別途検証する。
